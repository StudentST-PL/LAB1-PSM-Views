# LAB1-PSM-Views (Java + XML)

Aplikacja zrealizowana w ramach laboratoriów z Programowania Systemów Mobilnych (PSM).
Projekt realizuje tę samą funkcjonalność co wersja Compose (ukrywanie i pokazywanie danych na wizytówce), ale wykorzystuje klasyczne podejście do budowania interfejsów na Androidzie.

**Technologie:**
* Język: Java
* Interfejs użytkownika: Pliki XML (ConstraintLayout)
* Obsługa widoków: View Binding
